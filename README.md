# Data Science & Analytics Internship project
This repository contains three data analysis and visualization projects completed during my Data Science & Analytics Internship, using Power BI Desktop for dashboard creation and insights generation.

1. Advertising Data Analysis

Objective: Analyze advertising campaign performance to understand which channels generate the highest engagement and ROI.
Key Insights:

* Identified top-performing ad channels based on CTR and conversion rates.
* Discovered seasonal trends impacting ad effectiveness.
* Recommended data-driven strategies for ad budget allocation.

2. Online Retail Sales Analysis

Objective: Explore online retail data to evaluate sales performance, customer behavior, and revenue growth.
Key Insights:

* Highlighted top-selling products and customer segments contributing to maximum revenue.
* Detected sales patterns across regions and time periods.
* Built an interactive dashboard for real-time sales tracking and decision-making.

3. Student Satisfaction Survey Analysis

Objective: Assess student satisfaction levels across various academic and non-academic parameters.
Key Insights:

* Identified key factors influencing overall satisfaction scores.
* Visualized trends in course satisfaction, faculty feedback, and infrastructure quality.
* Provided actionable insights to improve student experience and engagement.

## Tools & Technologies

* Power BI Desktop – Dashboard development and visualization

* Microsoft Excel / CSV Files – Data preprocessing and cleaning

* Data Analytics Techniques – Descriptive analysis, KPI measurement, and trend evaluation

## Outcomes

These dashboards provide meaningful insights through visual storytelling, enhancing business decision-making and academic feedback processes.
